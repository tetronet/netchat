# Netchat
Fast, reliable, secure (E2E encrytion), messages aren't stored anyway except your local machine.
### How to use
1) Enter the tetronet address you will be chatting with
2) Enter it's password (used for the encryption)
3) Use textbox below and "Send" button
4) All received messages will appear in the list
### Connection
1) Create "cias.txt" in the same directory as the executable
2) Put your CIAS (Copybook Internet Access Server) here
3) You could use wss://data-set.su:3000/, but it's my server, it can be overloaded, so if you need reliability, make your own server
4) Once you open up the messager, it's gonna connect
### Features
No rare features, just a protected chat, no file sending or calls, but I'm gonna add that later on.
### Disclaimer
This is a test project, developed in like 1 hour, so it's working, but it's not like a normal messager. But I'm gonna develop it and make it work better.
